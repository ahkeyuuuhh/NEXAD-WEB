### Mockup Assets

- Screenshots should be 375x812px (iPhone dimensions) for best fit

## Asset Guidelines

### Screenshots
- Use actual app screenshots from the NEXAD mobile app
- Ensure screenshots show the monochrome design system
- Crop to remove status bars and navigation elements
- Optimize for web (compress to ~100KB each)

### Logo Usage
- The SVG logo matches the app's design system
- Uses the same color palette (#111111 background, #FFFFFF foreground, #F97316 accent)
- Scalable for all screen sizes

### Social Media
- OG image should feature the app interface with the NEXAD branding
- Include tagline: "AI-Enhanced Consultation System"
- Use the monochrome color scheme

## File Formats
- **SVG**: For logos and icons (scalable)
- **PNG**: For icons with transparency
- **JPG**: For screenshots and photos
- **ICO**: For favicon only

## Optimization
- Compress all images for web performance
- Use appropriate dimensions for each use case
- Consider WebP format for modern browsers (with JPG fallback)
